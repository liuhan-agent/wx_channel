# 微信视频号评论图片与贴纸资产设计

## 目标

让 wx_channel 从视频号评论响应中的 `contentInfo.imageInfos` 和
`contentInfo.emoticonInfos` 识别真实媒体，并把可验证的本地图片或贴纸资产交给
TrendRadar 的既有媒体理解流程。

真实只读探针已确认：贴纸评论可能仍携带 `contentType=1`，但同时包含
`contentInfo.emoticonInfos`。因此不再把 `contentType` 作为媒体类型的唯一依据。

## 安全边界

- `EncryptUrl`、`AesKey`、带查询参数的媒体 URL 和任何会话材料只在 wx_channel
  受控运行进程的内存中使用，绝不写入 JSONL、日志、清理回执或 TrendRadar 数据库。
- wx_channel 只把下载并验证后的本地文件、相对路径、SHA-256、字节数和受控媒体类型
  写入批次；文件路径必须位于该批次的媒体目录内。
- 解析到的 URL 必须经过 HTTPS、无用户信息和主机 allowlist 校验，并受每评论、每批次、
  文件大小、超时和重定向限制约束。
- 加密贴纸先在内存解密，只有通过图片格式、尺寸和大小校验后才原子写入本地资产目录。
  未验证的密文和明文临时文件都在当前运行根目录清理。

## 数据流

1. 评论解析器先保留现有文字、关系和分页语义，再从 `contentInfo` 提取图片和贴纸描述。
2. 图片候选使用已确认的图片字段；贴纸候选使用表情包描述中的标识、URL 和临时解密材料。
3. wx_channel 在本机受控运行期按上限下载、验证并在需要时解密候选，生成内容寻址的媒体
   文件。候选失败只影响该媒体项，评论仍正常入库。
4. 批次 schema v2 新增媒体资产清单和受限媒体目录；资产清单通过评论的稳定来源引用关联
   到已输出评论，而不携带 URL 或解密材料。
5. TrendRadar 将 schema v2 作为独立封闭合同验证：校验清单行、相对路径、哈希、大小、
   媒体类型和评论关联，再把本地资产交给现有下载/视觉理解存储流程。v1 保持原样，拒绝
   v1/v2 字段混用。

## 运行与失败语义

- `imageInfos` 非空时，评论归类为 `image`；`emoticonInfos` 非空时归类为 `sticker`。
  同时出现时保留两个媒体项。
- 不可下载、解密失败、格式无效、超限或主机不在 allowlist 的候选被跳过并记录闭合的
  `media_unavailable` 原因，不暴露 URL、密钥或原始响应。
- 媒体项失败不改变评论分页、回复分页、幂等键或批次的内容采集状态；只有协议验证或
  运行时清理失败才影响批次安全状态。
- 实施前先对真实响应做一次只读资源形状验证，确认图片 URL 的主机类别及贴纸加密格式；
  不凭字段名称假定 AES 模式、IV 或编码。

## 兼容性

- wx_channel 和 TrendRadar 继续接受现有 schema v1 批次；v1 不会产生媒体资产。
- 启用媒体资产后发出完整 schema v2 批次。验证器只接受该版本允许的文件和字段集合。
- TrendRadar 的通用视觉理解、媒体存储、重试和报告流程复用现有实现；本次不新建第二套
  AI 或下载调度流程。

## 已验证事实（2026-08-27）

- TrendRadar fixture 已完成 schema v2 的封闭验证、评论导入、本地媒体对象入库和视觉
  可读性端到端测试；验证结果为评论保留、媒体哈希一致、视觉提取成功。
- 本地媒体导入复用 TrendRadar 既有 `MediaAssetRepository`、`LocalMediaAssetStore` 和
  视觉提取服务，不新增远端下载器，也不把 wx_channel 的媒体候选定位符带出运行时。
- 端到端自动化验证覆盖图片媒体；加密贴纸的真实解密参数仍未从生产响应中确认，因此不
  将“加密贴纸已可解密”写入交付结论。
- 自动化测试不等同于真实 PC 微信验收。真实验收仍需登录 PC 微信、启动受控运行时、按
  既有入口/页面桥流程操作，并在 Windows 根 CA 安全警告出现时由人工确认。

## 验证计划

1. wx_channel fixture 覆盖纯文本、直接图片、加密贴纸、空媒体数组、混合媒体和不合法
   输入；断言密钥和 URL 从所有输出中缺失。
2. 资产写入测试覆盖路径穿越、超限、哈希不符、格式不符、重复候选和原子清理。
3. 批次测试覆盖 v1 保持可读、v2 完整媒体清单、v1/v2 混用拒绝及媒体失败不丢评论。
4. TrendRadar 测试覆盖 v2 清单验证、资产关联、哈希验证和既有视觉理解候选发现。
5. 真实受控运行用含贴纸评论的作品验收：确认评论入库、资产哈希存在、无 URL/密钥泄露、
   清理回执全部为真。图片下载验收在探测到非空 `imageInfos` 的真实样本后单独执行。

## 非目标

- 不自动化搜索或点击 PC 微信页面。
- 不修改评论、回复分页及其 marker 语义。
- 不把加密 URL 或 AES 密钥交给 TrendRadar，也不在浏览器进程外复用微信登录态。
